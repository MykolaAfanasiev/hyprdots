Небольшая консольная утилита для создания скриншотов в **Wayland**, разработанная для управления с клавиатуры в **Hyprland**.

## О проекте

`Screenshot Tool` объединяет `grim`, `slurp`, `satty`, `wl-copy` и системные уведомления в одной простой команде.

Утилита умеет делать скриншот всего экрана или выбранной области, открывать изображение в Satty, копировать его в буфер обмена, сохранять в файл или совмещать эти действия. Она также интегрирована в конфигурацию Hyprland через отдельный screenshot submap.

## Возможности

- Скриншот всего экрана через `grim`
- Интерактивный выбор области через `slurp`
- Необязательное редактирование и аннотирование в `satty`
- Копирование изображения через `wl-copy`
- Необязательное сохранение в файл
- Пользовательский путь сохранения
- Системные уведомления
- Проверка зависимостей с учётом выбранных опций
- Установка настоящей команды `screenshot-tool`
- Screenshot submap для Hyprland

## Поведение по умолчанию

Запуск без дополнительных опций:

```bash
screenshot-tool
```

выполняет следующие действия:

1. делает скриншот всего экрана;
2. копирует изображение в буфер обмена;
3. сохраняет его в `~/Screenshots`;
4. показывает системное уведомление.

Имя файла создаётся в следующем формате:

```text
screenshot_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.png
```

## Требования

### Python

- Python 3.10 или новее
- Click 8.1 или новее

### Внешние команды

| Команда | Пакет или программа | Назначение | Когда необходима |
|---|---|---|---|
| `grim` | grim | Создание скриншотов | Всегда |
| `notify-send` | libnotify | Системные уведомления | Всегда |
| `slurp` | slurp | Выбор области | При использовании `--area` |
| `satty` | satty | Редактирование скриншотов | При использовании `--edit` |
| `wl-copy` | wl-clipboard | Копирование изображения | Когда включено копирование |

### Arch Linux

```bash
sudo pacman -S grim slurp satty wl-clipboard libnotify python-pipx
```

## Установка

В `pyproject.toml` зарегистрирована консольная команда `screenshot-tool`.

### Установка в editable-режиме

Этот вариант удобен во время разработки: изменения исходного кода применяются без повторной установки.

```bash
cd ~/.config/.dotfiles/scripts/screenshot
pipx install --editable .
```

Убедись, что каталог с командами Pipx добавлен в `PATH`:

```bash
pipx ensurepath
```

Перезапусти терминал и проверь установку:

```bash
command -v screenshot-tool
screenshot-tool --help
```

### Переустановка после изменения конфигурации пакета

```bash
pipx reinstall screenshot-tool
```

### Удаление

```bash
pipx uninstall screenshot-tool
```

## Использование

```text
Usage: screenshot-tool [OPTIONS]

Options:
  --area / --fullscreen  Выбрать область или сделать скриншот всего экрана.
  --edit / --no-edit     Открыть скриншот в Satty.
  --copy / --no-copy     Скопировать изображение в буфер обмена.
  --save / --no-save     Сохранить изображение в файл.
  -o, --output FILE      Указать пользовательский путь сохранения.
  --help                 Показать справку.
```

## Примеры

### Весь экран, копирование и сохранение

```bash
screenshot-tool
```

### Выбор области, копирование и сохранение

```bash
screenshot-tool --area
```

### Выбор области с редактированием

```bash
screenshot-tool --area --edit
```

### Копирование без сохранения

```bash
screenshot-tool --no-save
```

Для копирования создаётся промежуточный файл, который удаляется после завершения операции.

### Сохранение без копирования

```bash
screenshot-tool --no-copy
```

### Сохранение по выбранному пути

```bash
screenshot-tool --output ~/Pictures/example.png
```

Если родительского каталога нет, он будет создан автоматически.

### Выбор области, редактирование и копирование без сохранения

```bash
screenshot-tool --area --edit --no-save
```

## Интеграция с Hyprland

Утилита подключена к Lua-конфигурации Hyprland.

### Быстрый скриншот

| Клавиша | Действие |
|---|---|
| `Print` | Скриншот всего экрана, копирование и сохранение |

### Открытие меню скриншотов

| Клавиша | Действие |
|---|---|
| `Super + Shift + S` | Открыть screenshot submap |

### Выбор режима захвата

| Клавиша | Действие |
|---|---|
| `F` | Варианты для всего экрана |
| `A` | Варианты для выбранной области |
| `Esc` | Закрыть меню скриншотов |

### Действия со скриншотом

Следующие клавиши работают как в fullscreen-, так и в area-submap:

| Клавиша | Действие |
|---|---|
| `1` | Скопировать и сохранить |
| `2` | Отредактировать, скопировать и сохранить |
| `3` | Скопировать без сохранения |
| `4` | Отредактировать и скопировать без сохранения |
| `5` | Сохранить без копирования |
| `6` | Отредактировать и сохранить без копирования |
| `Esc` | Вернуться к выбору режима захвата |
| `Shift + Esc` | Закрыть все screenshot submap |

Файл интеграции:

```text
configs/hypr/modules/submaps/screenshot.lua
```

## Коды завершения

| Код | Значение |
|---:|---|
| `0` | Операция успешно завершена |
| `1` | Выбор области отменён |
| `2` | Не удалось создать скриншот |
| `3` | Редактирование отменено или завершилось ошибкой |
| `4` | Не удалось скопировать изображение |

Click сообщает об отсутствующих зависимостях и неправильных сочетаниях опций до запуска основной логики скриншота.
