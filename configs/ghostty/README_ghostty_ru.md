# Ghostty

[English version](README_ghostty.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Конфигурация терминала, keybindings, launcher и интеграция с генерируемой темой.

## Файлы

- `config.ghostty`
- `keybindings.conf`
- `launch.sh`
- `layout.conf`
- `prepare-theme.sh`
- `themes/catppuccin-mocha.conf`
- `themes/current.conf`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
