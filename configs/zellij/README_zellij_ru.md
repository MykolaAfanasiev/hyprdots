# Zellij

[English version](README_zellij.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Основной локальный terminal multiplexer, launcher и подготовленная runtime-тема.

## Файлы

- `config.kdl`
- `launch.sh`
- `prepare-theme.sh`
- `themes/current.kdl`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
