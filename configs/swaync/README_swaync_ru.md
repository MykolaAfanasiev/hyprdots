# SwayNC

[English version](README_swaync.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Notification center, CSS layout, управление и интеграция с генерируемой темой.

## Файлы

- `config.json`
- `launch.sh`
- `layout.css`
- `prepare-theme.sh`
- `scripts/control.sh`
- `style.css`
- `themes/catppuccin-mocha.css`
- `themes/current.css`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
