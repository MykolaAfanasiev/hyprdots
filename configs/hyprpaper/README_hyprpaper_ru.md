# Hyprpaper

[English version](README_hyprpaper.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Конфигурация wallpaper daemon и helper scripts для управления/перезапуска.

## Файлы

- `hyprpaper.conf`
- `launch.sh`
- `scripts/control.sh`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
