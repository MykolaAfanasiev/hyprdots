# Yazi

[English version](README_yazi.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Конфигурация terminal file manager, packages, keymaps, launcher и live reload темы.

## Файлы

- `keymap.toml`
- `launch.sh`
- `package.toml`
- `reload-theme.sh`
- `theme.toml`
- `yazi.toml`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
