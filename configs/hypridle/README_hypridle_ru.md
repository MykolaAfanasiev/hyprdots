# Hypridle

[English version](README_hypridle.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Idle-таймеры и helper scripts для яркости, блокировки и питания.

## Файлы

- `hypridle.conf`
- `launch.sh`
- `scripts/brightness.sh`
- `scripts/lock.sh`
- `scripts/poweroff.sh`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
