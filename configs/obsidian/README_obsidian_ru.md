# Obsidian

[English version](README_obsidian.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Helper для установки theme snippet в найденные Obsidian vaults.

## Файлы

- `apply-theme.sh`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
