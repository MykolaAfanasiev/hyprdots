> [!IMPORTANT]
> Это личная конфигурация, а не универсальный установщик. Перед использованием на другом компьютере проверь настройки монитора, приложений и путей.

## Обзор

В этой папке находится часть моих dotfiles, относящаяся к Hyprland. Конфигурация разделена на небольшие Lua-модули: монитор, устройства ввода, внешний вид, анимации, автозапуск, правила окон, бинды, submap-режимы и специальные рабочие пространства.

Основные принципы конфигурации:

- управление преимущественно с клавиатуры;
- небольшие переиспользуемые Lua-модули;
- перемещение фокуса в стиле Vim;
- именованные специальные рабочие пространства;
- многоступенчатое меню скриншотов;
- история буфера обмена и управление уведомлениями;
- плавные, но относительно лёгкие анимации.

## Основные возможности

- Модульная точка входа `hyprland.lua`
- Английская и русская раскладки
- Переключение раскладки через `Alt + Shift`
- Раскладка окон Dwindle с сохранением направления разделения
- Перемещение фокуса клавишами `H`, `J`, `K` и `L`
- Рабочие пространства `1`–`10`
- Специальные пространства для терминала, заметок и системного монитора
- Меню скриншотов, связанное с `screenshot-tool`
- История буфера обмена через `cliphist`
- Управление мультимедиа, громкостью и яркостью
- Жест тачпада для переключения рабочих пространств

## Назначение модулей

| Модуль | Назначение |
|---|---|
| `hyprland.lua` | Подключает все модули конфигурации |
| `monitor.lua` | Выход монитора, разрешение, положение и масштаб |
| `input.lua` | Раскладки, параметры указателя и жесты |
| `decoration.lua` | Отступы, рамки, скругление, тени и размытие |
| `animations.lua` | Кривые, пружины, анимации и параметры раскладок |
| `autostart.lua` | Запускает обои, панель, уведомления, буфер обмена и idle-службы |
| `windowsrules.lua` | Правила окон и XWayland |
| `special_workspaces.lua` | Именованные специальные рабочие пространства |
| `submaps/submaps.lua` | Основные бинды и подключение submap-режимов |
| `submaps/screenshot.lua` | Меню выбора режима скриншота |
| `submaps/clean.lua` | Минимальный submap с выходом в обычный режим |
| `vars/global.lua` | Главный модификатор и команды приложений |
| `vars/variables.lua` | Переменные Wayland, курсора, toolkit и XDG |

## Требования

### Основные

- Hyprland с поддержкой Lua-конфигурации
- GNU Stow или другой способ создания символических ссылок

### Команды, используемые конфигурацией

Конфигурация запускает следующие программы. Устанавливай только те компоненты, которыми собираешься пользоваться:

| Назначение | Команды |
|---|---|
| Терминал | `kitty` |
| Меню приложений | `wofi` |
| Панель | `waybar` |
| Уведомления | `swaync`, `swaync-client`, `notify-send` |
| Обои | `hyprpaper` |
| Управление бездействием | `hypridle` |
| Буфер обмена | `cliphist`, `wl-copy`, `wl-paste`, `wl-clip-persist` |
| Скриншоты | `screenshot-tool` |
| Яркость | `brightnessctl` |
| Звук | `pactl` |
| Мультимедиа | `playerctl` |
| Пространство заметок | `obsidian` |
| Системный монитор | `btop` |

Проверить наличие команды:

```bash
command -v kitty
```

## Установка

Сейчас в конфигурации есть пути, рассчитанные на расположение репозитория здесь:

```text
~/.config/.dotfiles
```

Клонируй репозиторий в эту папку:

```bash
git clone <repository-url> "$HOME/.config/.dotfiles"
```

Перед продолжением сохрани резервную копию существующей конфигурации Hyprland:

```bash
mv "$HOME/.config/hypr" "$HOME/.config/hypr.backup"
mkdir -p "$HOME/.config/hypr"
```

Подключи пакет Hyprland через GNU Stow:

```bash
stow \
  --dir="$HOME/.config/.dotfiles/configs" \
  --target="$HOME/.config/hypr" \
  hypr
```

Перезагрузи конфигурацию:

```bash
hyprctl reload
```

Для обновления символических ссылок:

```bash
stow --restow \
  --dir="$HOME/.config/.dotfiles/configs" \
  --target="$HOME/.config/hypr" \
  hypr
```

## Настройка перед первым запуском

### Монитор

Текущая конфигурация рассчитана на следующие параметры:

```lua
hl.monitor({
  output = "eDP-1",
  mode = "preferred",
  position = "auto",
  scale = "1.33",
})
```

Посмотреть названия мониторов:

```bash
hyprctl monitors
```

После этого измени файл:

```text
modules/monitor.lua
```

### Приложения и модификатор

Команды приложений и основной модификатор находятся в:

```text
modules/vars/global.lua
```

Текущие значения:

```lua
M.mainMod = "SUPER"
M.terminal = "kitty"
M.fileManager = "dolphin"
```

### Пути репозитория

Некоторые команды напрямую используют путь:

```text
$HOME/.config/.dotfiles/configs/hypr
```

Оставь репозиторий в `~/.config/.dotfiles` либо измени пути в файлах:

- `modules/autostart.lua`
- `modules/vars/global.lua`

### Вспомогательные конфигурации

`autostart.lua` и `global.lua` ссылаются на конфигурационные файлы для:

- Hyprpaper
- Hypridle
- Waybar
- SwayNC
- Wofi

Эти файлы должны находиться по указанным путям. В противном случае измени команды под собственную структуру конфигурации.

## Горячие клавиши

Основной модификатор по умолчанию — `SUPER`.

### Приложения и системные действия

| Сочетание | Действие |
|---|---|
| `SUPER + Enter` | Открыть Kitty |
| `SUPER + Space` | Открыть Wofi |
| `Ctrl + X` | Закрыть активное окно |
| `Alt + N` | Открыть или закрыть SwayNC |
| `SUPER + Shift + V` | Открыть историю буфера обмена |
| `Print` | Сделать быстрый скриншот |
| `SUPER + Shift + S` | Открыть меню скриншотов |

### Управление окнами

| Сочетание | Действие |
|---|---|
| `SUPER + F` | Переключить плавающий режим |
| `SUPER + Shift + F` | Переключить полноэкранный режим |
| `SUPER + V` | Изменить направление разделения Dwindle |
| `SUPER + H/J/K/L` | Переместить фокус влево/вниз/вверх/вправо |
| `SUPER + Tab` | Перейти на следующий монитор |
| `SUPER + Shift + Tab` | Переместить активное окно на следующий монитор |
| `SUPER + левая кнопка мыши` | Переместить окно |
| `SUPER + правая кнопка мыши` | Изменить размер окна |

### Рабочие пространства

| Сочетание | Действие |
|---|---|
| `SUPER + 1…9` | Перейти на пространство `1…9` |
| `SUPER + 0` | Перейти на пространство `10` |
| `SUPER + Shift + 1…9` | Переместить окно на пространство `1…9` |
| `SUPER + Shift + 0` | Переместить окно на пространство `10` |
| `SUPER + колёсико мыши` | Переключаться между существующими пространствами |

### Специальные рабочие пространства

Если специальное пространство пустое, соответствующее приложение запускается автоматически.

| Пространство | Показать или скрыть | Переместить активное окно | Приложение |
|---|---|---|---|
| Терминал | `SUPER + T` | `SUPER + Shift + T` | `kitty` |
| Заметки | `SUPER + N` | `SUPER + Shift + N` | `obsidian` |
| Мониторинг | `SUPER + B` | `SUPER + Shift + B` | `kitty -e btop` |

### Мультимедийные клавиши

Стандартные клавиши яркости, громкости, отключения звука, воспроизведения, следующего и предыдущего трека настроены через `brightnessctl`, `pactl` и `playerctl`.

## Screenshot submap

Интеграция скриншотов ожидает исполняемый файл:

```text
~/.local/bin/screenshot-tool
```

Подробная документация скрипта находится здесь:

```text
../../scripts/screenshot/README.ru.md
```

Открытие меню скриншотов:

```text
SUPER + Shift + S
```

Сначала выбери тип снимка:

| Клавиша | Режим |
|---|---|
| `F` | Весь экран |
| `A` | Выбранная область |
| `Esc` | Закрыть меню скриншотов |

Затем выбери действие:

| Клавиша | Копировать | Сохранить | Редактировать |
|---|:---:|:---:|:---:|
| `1` | Да | Да | Нет |
| `2` | Да | Да | Да |
| `3` | Да | Нет | Нет |
| `4` | Да | Нет | Да |
| `5` | Нет | Да | Нет |
| `6` | Нет | Да | Да |

Внутри подменю:

- `Esc` возвращает к выбору типа снимка.
- `Shift + Esc` полностью закрывает все screenshot submap.

## Аварийный выход из submap

| Сочетание | Действие |
|---|---|
| `SUPER + Ctrl + Shift + C` | Войти в `clean` submap |
| `SUPER + Ctrl + Shift + Esc` | Выйти из `clean` submap |
| `SUPER + Ctrl + Shift + Alt + Esc` | Универсально вернуться к глобальным биндам |

## Настройки ввода

Текущая конфигурация клавиатуры:

```text
Раскладки:    us, ru
```

## Решение проблем

### Перезагрузить конфигурацию

```bash
hyprctl reload
```

### Посмотреть ошибки конфигурации

```bash
hyprctl configerrors
```

### Проверить символические ссылки

```bash
ls -la "$HOME/.config/hypr"
```

### Команда из бинда не запускается

Проверь, доступна ли она в окружении Hyprland:

```bash
command -v screenshot-tool
```

Если программа установлена в `~/.local/bin`, эта папка должна присутствовать в `PATH` ещё до запуска Hyprland.

### Не запускается компонент автозапуска

Выполни его команду вручную в терминале, а затем проверь пути в `modules/autostart.lua` и `modules/vars/global.lua`.

## Текущие ограничения

- Название и масштаб монитора зависят от конкретного компьютера.
- Несколько путей предполагают расположение репозитория в `~/.config/.dotfiles`.
- Конфигурации Waybar, SwayNC, Wofi, Hyprpaper и Hypridle упоминаются, но не находятся в этой папке Hyprland.
- Некоторые приложения являются личными значениями по умолчанию и могут отсутствовать на другом компьютере.

## Лицензия

Конфигурация распространяется на условиях лицензии, расположенной в корне репозитория.
