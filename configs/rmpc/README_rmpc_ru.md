# RMPC

[English version](README_rmpc.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Конфигурация terminal MPD client, launcher и интеграция с темой.

## Файлы

- `config.ron`
- `launch.sh`
- `themes/catppuccin-mocha.ron`
- `themes/current.ron`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
