# btop

[English version](README_btop.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Конфигурация системного монитора, launcher, live reload темы и ссылки на палитры.

## Файлы

- `btop.conf`
- `launch.sh`
- `reload-theme.sh`
- `themes/catppuccin_mocha.theme`
- `themes/current.theme`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
