# Waybar

[English version](README_waybar.md) · [Конфигурации](../README_configs_ru.md) · [Проект](../../README_ru.md)

## Назначение

Конфигурация панели, scripts, CSS layout и интеграция с темой.

## Файлы

- `config.jsonc`
- `launch.sh`
- `prepare-theme.sh`
- `scripts/clock.sh`
- `style.css`
- `themes/catppuccin-mocha.css`
- `themes/current.css`



## Разработка

Исходная конфигурация хранится в репозитории и разворачивается installer/Stow workflow. Генерируемое и изменяемое runtime-состояние по возможности должно оставаться вне отслеживаемых source-файлов.
